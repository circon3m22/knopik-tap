# Knopik TAP 1.1.0 — Большое путешествие

Обновление подготовлено для `circon3m22/knopik-tap`, ветка
`codex/tap-journey-arcade`. Изменения не относятся к Knopik GO.

## Интерфейс

Светлое главное меню, один следующий шаг, яркие акценты и тактильные кнопки.
Собственный Кнопик и все его эмоции, уши и аксессуары сохранены. Нижнее меню:
Магазин / Кнопик / Игры / Путь / Кейсы. Настройки и аккаунт открываются через
профиль вверху; права администратора сохранены.

Оригинальные цветные SVG-значки находятся в `app/tap-icon.tsx`, обложки игр —
в `app/arcade-art.tsx`. Они нарисованы вручную кодом, без шрифта значков,
внешней библиотеки и копирования файлов Duolingo. У сейфа отдельная металлическая
дверца с кодовым диском; сундук обозначает только кейсы и награды глав.
Интерфейс учитывает клавиатуру, safe areas и уменьшение анимации.

## Путь и уровни

- 24 последовательных этапа в четырёх главах. Тапы, точность, память и сейф.
- Награда этапа: 50/80/110/140 XP и 100/200/300/400 монет по главе.
- За завершение главы дополнительно выдаётся один обычный кейс. Если запас
  кейсов заполнен, этап не расходуется: сначала нужно освободить место.
- 30 уровней опыта. Обычный тап даёт 1 XP, завершённая игра — 10 XP,
  победа в игре на навык — 40 XP вместо 10. XP не зависит от размера ставки.
- «Монетка» открывается после этапа 2, «Кубик» после 6, «Башня» после 12.
  Все три прежние игры доступны сразу. Весь путь проходится без ставок.
- Прежняя монетная шкала остаётся мастерством: её бонус к тапам и ранее
  полученные кейсы сохраняются. Бонус виден в статистике профиля.

## Библиотека игр

Карточки открывают описание и правила; открытие карточки не списывает монеты.
Категории: все игры, на навык, на удачу. Экран новой игры сохраняет выбранную
карточку при возврате. Фокус удерживается в новом диалоге и возвращается назад.

| Игра | Механика | Выплата / награда |
| --- | --- | --- |
| Точный тап | Остановить бегунок в зоне 36–64%; два попадания из трёх | Бесплатно, 10 XP; победа 40 XP и 25 монет |
| Память Кнопика | Повторить четыре плитки; два верных раунда из трёх | Бесплатно, 10 XP; победа 40 XP и 25 монет |
| Колесо удачи | Прежняя рулетка и её баланс | Существующие правила, дополнительно 10 XP за завершение |
| Три барабана | Прежние слоты | Существующие правила, дополнительно 10 XP |
| Пять кнопок | Прежние мины и вывод между раундами | Существующие правила, дополнительно 10 XP |
| Монетка | Солнце / луна, равновероятные исходы | 50%, ×1,9 с учётом ставки; 10 XP независимо от исхода |
| Кубик | Числа 1–3 / 4–6, шесть равновероятных граней | 50%, ×1,9 с учётом ставки; 10 XP |
| Башня сокровищ | Две безопасные плитки из трёх, пять этажей | ×1,4 / ×2,1 / ×3,15 / ×4,72 / ×7,08; 10 XP |

У башни явный вывод после успешного этажа и автоматический вывод на вершине.
Новые игры на удачу дают выбрать ставку без требования купить аксессуар.
Они не используют скрытую сложность: показанные вероятности постоянны.
У старых игр прежняя сложность и условия эрокеза не изменены; это объяснено
в правилах. Сейф не участвует в ставках, покупки и вывод реальных денег отсутствуют.

Прежние игровые напитки остаются билетами: Питбуль — рулетка, Какао — слоты,
Бергамот — мины. Если билета нет, применяется прежняя цена входа 200/200/300
монет, показанная до запуска. Кнопки этих игр убраны из полосы напитков и
перенесены в библиотеку, как в GO. Корм, ускорение и щит остаются усилениями.

## Сохранения и защита от повторов

SAVE_VERSION 15 → 16. Добавлено вложенное поле `adventure`; кошелёк, сейф,
инвентарь, одежда, прежние уровни и настройки сохраняются без сброса. Для
старого аккаунта XP учитывает прежнее число тапов и уровень; прохождение
новых этапов начинается с первого. Сериализация проходит через существующую
очередь, локальную копию и CAS-ревизии. SQL, авторизация, RLS и Supabase RPC
не изменялись. Старый клиент с версией сохранения 15 не должен перезаписывать 16:
существующая защита от будущего формата остаётся в силе.

Родитель хранит текущую ставку и признак расчёта. Повторный результат или
старый id раунда не выплачивается. Баланс обновляется синхронно в ref перед
React, поэтому быстрые действия не используют один старый остаток. Награда
этапа проверяет ожидаемый индекс; быстрый двойной клик не забирает следующий.
После ставки новый диалог закрывается только после результата или вывода.

## Скиллы проекта

В `.agents/skills/` подключены `knopik-ui`, `ui-ux-pro-max`, `frontend-design`,
`webapp-testing`. Продуктовый бриф находится в `knopik-ui/SKILL.md`, маршрут
подключения — в корневом `AGENTS.md`. Для сторонних файлов сохранены лицензии,
upstream commit SHA и контрольные суммы в `sources.lock.json`. Они не входят
в игровые бандлы. Для поиска UX достаточно Python 3; ключи API не нужны.

## Проверки

- 72 проверки Node, включая миграцию, весь путь без казино, уровни, ставки,
  повторные выплаты, память, тайминг и прежние игровые регрессии.
- TypeScript проходит. ESLint новых компонентов/движков и обновлённого
  `mini-game-panel.tsx` проходит без ошибок и предупреждений.
- Полный ESLint выявляет прежние 13 ошибок React Hooks в `page.tsx`,
  `cloud-account.tsx`, `update-center.tsx`. Те же правила нарушались на
  исходном коммите: синхронизация состояния в эффектах, чтение ref/времени.
  Правила не отключались. Полный lint не отмечается как успешный.
- Сборки vinext и статического GitHub Pages экспорта проверяются отдельно.
- `scripts/qa-journey.py`: 16 браузерных сценариев в Chromium, включая пять
  размеров 320×568, 375×667, 390×844, 768×1024, 1440×900, геометрию, фильтры,
  клавиатуру, главу и кейс, быстрые клики, проигрыш/выигрыш/вывод,
  обычный и спокойный тайминг, память и старые слоты. Ошибок JS не обнаружено.
- Браузерные сценарии используют перехват Supabase в тесте с фиктивным
  аккаунтом и CAS-ответами. Записей в рабочую базу не было; обхода входа
  в исходниках нет. Физический телефон и живой сервер Supabase не проверялись.

Команды:

```bash
npm ci
npx tsc --noEmit
npm run build
node --test --test-isolation=none tests/*.test.mjs
GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/knopik-tap npm run build:pages -- --webpack
# При запущенном локальном приложении; нужен Python Playwright и Chromium:
python3 scripts/qa-journey.py --url http://127.0.0.1:3001
```

Скриншоты и JSON-результаты браузера создаются в игнорируемой папке
`outputs/journey/`. Публикация в рабочую игру требует слияния PR и успешного
workflow GitHub Pages; создание ветки само по себе игру не обновляет.
