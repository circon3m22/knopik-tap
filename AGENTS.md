# Knopik TAP

Работай только с TAP. Knopik GO — отдельная игра; не меняй её исходники,
сохранения или таблицы. Next.js/React/TypeScript, CSS, исходные изображения Кнопика.

Для интерфейса сначала прочитай `.agents/skills/knopik-ui/SKILL.md`, затем по
задаче `ui-ux-pro-max`, `frontend-design`, `webapp-testing` в той же папке.
Принятое направление — светлый, простой и яркий интерфейс в духе Duolingo,
с собственным Кнопиком, читаемым прогрессом, округлыми тактильными кнопками.

Не сбрасывай баланс, предметы, старые уровни и настройки при миграции.
Сохраняй авторизацию, права администратора, ревизии и очередь облачных записей.
Новые игровые ставки списываются один раз; результат раунда начисляется один раз.
Игровые монеты не являются деньгами. Не добавляй оплату или вывод средств.

Выпуски оформляй по `docs/RELEASE_PROCESS.md`: версия, журнал, lockfile и PWA-кеш.
Проверяй игровые движки, миграцию, TypeScript, ESLint, сборки и реальный браузер.
Браузерные тесты с фиктивным аккаунтом используют только перехват API в тесте;
не добавляй обход авторизации в приложение. Изменения готовь отдельным PR.
