# KNOPIK TAP

Игра на GitHub Pages: https://circon3m22.github.io/knopik-tap/

## Игра

Новый игровой цикл строится вокруг ритма, настроения и риска. Обычный экран белый; счастье Кнопика постепенно добавляет синий. При высоком напряжении экран становится жёлтым, при укусе — красным. Сейф защищает монеты, а супертап награждает за отпускание в нужный момент.

Магазин, кейсы, задания, предметы, колесо риска, барабаны и мины работают с общим сохранением. Результат колеса и барабанов сохраняется до завершения анимации. Незавершённую игру в мины можно продолжить после перезагрузки.

## Запуск и проверки

Нужен Node.js 22.13 или новее.

- `npm ci` — установить зафиксированные зависимости.
- `npm run dev` — запустить разработку.
- `npm run test:unit` — проверить игровую логику и очередь сохранений.
- `npm test` — собрать приложение и выполнить все проверки.
- `npm run build:pages` — собрать Next.js; для статического экспорта задать `GITHUB_PAGES=true` и `NEXT_PUBLIC_BASE_PATH=/knopik-tap`.

GitHub Actions собирает и проверяет код перед публикацией. Рабочая ветка репозитория — `master`. Публикация выполняется штатным GitHub Pages action.

## Аккаунты и сохранения

Bober — игрок, Bobur — администратор. Пароли проверяются сервером Supabase Edge Function `knopik-account`. Паролей и серверных ключей в исходниках клиента нет. Администратор создаёт промокоды и меняет сложность; права проверяются сервером.

Клиент хранит локальную копию прогресса и последовательно отправляет изменения в облако. Номер редакции защищает от перезаписи прогресса с другого устройства. При ошибке сохранения появляется сообщение с возможностью повторить запрос. Старый вход через Supabase Auth больше не используется.

## Основные файлы

- `app/page.tsx` — игровой экран и разделы.
- `app/arcade.css` — единый адаптивный интерфейс.
- `app/arcade-engine.ts` — тапы, напряжение, покупки, сейф, кейсы и задания.
- `app/arcade-games.tsx` — мини-игры.
- `app/account-client.ts`, `app/cloud-account.tsx` — вход и синхронизация.
- `public/sw.js` — кэш приложения с обновлением версии.
